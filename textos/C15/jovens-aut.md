Tipo: autoridade (aut)
Formato escolhido: explicação prática

### FALA
"Trocar de base" parece abstrato até você ver um exemplo. Um jovem começando hoje monta um primeiro projeto real — um assistente que responde clientes, por exemplo — usando o modelo de IA que está bombando essa semana. Se ele construiu isso amarrado só naquele modelo, sem entender o que o projeto realmente precisa por trás, no dia que o modelo mudar de preço ou de regra, o projeto trava com ele. Quem aprende certo desde o primeiro projeto separa duas coisas: o que o projeto FAZ, e qual modelo está processando isso por trás. Aí, se precisar trocar, troca a peça, não o projeto inteiro. Quem constrói assim não depende de sorte, nem de país, nem de promoção — depende só de saber onde estão as costuras do próprio trabalho.

### SOBREPOSIÇÕES
ATENÇÃO (0–2s): "Seu primeiro projeto de IA já nasce refém — ou não, se você souber isso"
RETENÇÃO: contagem em duas partes — "o que o projeto faz" versus "qual modelo processa" — fechada na virada de saber trocar a peça.
PROVA: tela com esquema simples — projeto (assistente de clientes) no centro, e um bloco "modelo" plugável e trocável na lateral.
ENGAJAMENTO: convite a salvar — "salva isso pro seu primeiro projeto".
CTA (fecho): convite leve a seguir/testar — sem CTA comercial completo.

## ESTRUTURA
Fórmula: explicação prática com exemplo concreto (primeiro projeto de um iniciante) → demonstração da separação projeto/modelo → princípio reaplicável (saber onde estão as costuras do próprio trabalho).
