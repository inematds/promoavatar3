## Versão única
### FALA (texto para o HeyGen — falar exatamente isto)
Você paga três ferramentas pra postar todo dia. E ainda assim, o ritmo te esgota.

Imagina o criador que abre cinco abas diferentes só pra montar um post: uma pra ideia, uma pra imagem, uma pra legenda, uma pra agendar. No fim do mês, ele descobre que gastou mais tempo gerenciando ferramenta do que criando.

O problema não é falta de ferramenta. É excesso delas, cada uma fazendo um pedacinho, nenhuma pensando junto com você.

Comenta aqui quantas ferramentas diferentes você usa só pra postar um conteúdo.

### SOBREPOSIÇÕES DE TELA (NÃO falar)
ATENÇÃO (0-2s): você paga três ferramentas só pra postar
RETENÇÃO (miolo): cinco abas abertas pra montar um post só
PROVA: mais tempo gerenciando ferramenta do que criando
ENGAJAMENTO: comenta quantas ferramentas você usa pra postar
CTA (fecho): comenta o número agora
