Tipo: promocional
Formato escolhido: dor → consequência → primeiro passo

### FALA
Você já ouviu "não tem vaga" cem vezes.
A dor não é faltar vaga pra iniciante. É continuar treinando pra um cargo que a empresa já está tentando automatizar.
Se você passar mais um ano só empilhando curso de "como usar IA", vai chegar atrasado pra profissão que realmente vai sobrar: a de quem sabe dirigir agentes até o fim de um trabalho.
O primeiro passo não é currículo novo. É pegar uma tarefa repetitiva que você já faz e escrever, em ordem, cada decisão que você toma nela.
Isso vira o material que separa quem só usa ferramenta de quem comanda um processo.
Comenta "processo" se você topa escrever essa lista ainda essa semana — é o tipo de compromisso que só vale se alguém souber que você assumiu.
