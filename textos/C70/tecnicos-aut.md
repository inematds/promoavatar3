### FALA
Você entende IA pela metade se usa só prompt.
Tem uma diferença entre "pedir uma coisa" e "montar um sistema que pede sozinho toda vez".
Passo 1: pega uma tarefa que você repete toda semana — revisar PR, escrever changelog, o que for.
Passo 2: em vez de digitar o pedido de novo cada vez, escreve esse pedido uma única vez, com o contexto fixo que nunca muda.
Passo 3: reusa esse mesmo pedido toda vez que a tarefa aparece, ajustando só o que muda de verdade.
Isso é sistema. Prompt solto você refaz pra sempre; sistema você constrói uma vez.
O princípio: quem repete prompt trabalha pra IA, quem constrói sistema faz a IA trabalhar pra ele.
Segue se você quer ver mais sistema assim, e testa isso ainda essa semana.
