# C#183 — resumo estratégico (variante viral)

## ESSÊNCIA
O conteúdo afirma que usar IA como chat (pergunta → resposta → esquece) desperdiça o potencial dela: o salto é montar um ambiente de trabalho permanente — arquivos, contexto, instruções, regras, Skills e histórico — para a IA continuar projetos em vez de recomeçar. Fala com quem já usa IA no dia a dia e sente que repete explicações. NÃO é um tutorial de ferramenta específica, nem promessa de automação total: é uma mudança de mentalidade ("prompt é instrução momentânea; OSWork é construir o ambiente onde a IA trabalha").

## Assunto
OSWork: IA como sistema de trabalho (Chat → Arquivos → Markdown → AGENTS.md → Skills → Git → Telegram → VPS).

## Tese central
Quem só troca de prompt recomeça do zero todo dia; quem monta o lugar onde a IA trabalha, continua de onde parou.

## Motivo para assistir agora
Relevância prática (sem elemento temporal no assunto): o erro comum de re-explicar tudo a cada conversa, que piora quanto mais a pessoa usa.

## Elemento demonstrável
Antes/depois: chat vazio re-explicando o contexto × pasta com arquivo de contexto, regras, procedimentos e histórico; a página única sendo escrita.

## Ganchos (5 candidatos, ideia-base)
1. "Você explica tudo de novo toda vez."
2. "A IA esquece você toda vez que fecha." (60mais)
3. "Seu colega não é melhor. A IA dele lembra." (profissionais)
4. "Você coleciona prompt. Deveria construir o ambiente." (técnicos)
5. "Você trata a IA como um estranho. Toda vez." (pessoacomum)
Venceu a família "perda/repetição": abre lacuna (por quê? o que fazer?) e acerta **perda do que já é seu** (o que você disse some) + **vergonha auto-dirigida** de já ter percebido. Cada público recebeu a própria variação (≤9 palavras).

## Diferenciação por tipo (vale para os 12 públicos)
- **-alc** — consequência inesperada. Gancho de perda + cena do público → virada "não é a pergunta, é o lugar" → frase repetível "Prompt é instrução do momento. O ambiente é o que fica." → **escolha binária nomeada** (1 = explico tudo de novo; 2 = minha IA já sabe quem eu sou).
- **-aut** — conceito explicado. Gancho "usa pela metade" → prompt é metade → **contagem das 4 peças** (contexto, regras, passo a passo, histórico) → ganho do público → princípio "a pergunta vira 'onde a minha IA trabalha'" → **salvar**.
- **-pro** — direção. Gancho do primeiro passo → dor da repetição → "não melhora sozinho" → **primeiro passo nomeado de hoje** (uma página específica do público) → **compromisso público** nos comentários.

Por público muda: gancho, cena em 2ª pessoa, o que é re-explicado, o ganho, o primeiro passo (ex.: 40mais = método próprio escrito; educadores = planejamento como para substituto; empreendedores = manual do negócio; recolocacao = história profissional escrita uma vez; tecnicos = arquivo de instruções do agente) e a imagem de capa.

## Riscos de repetição / revisão humana
- Os três tipos usam esqueleto comum entre públicos (gerado por `scripts/gen_c183.py`): miolos do -alc e do -aut se repetem quase literais entre os 12 públicos — se publicar vários públicos no mesmo canal, revisar.
- Imagens 2–6 são iguais entre públicos do mesmo tipo; só a IMAGEM 1 (capa) é por público.
- Duração: FALAS de 108–131 palavras (~36–44s) — no limite de 45s; conferir no HeyGen.
- Nomes do assunto (Codex, AGENTS.md, Telegram, VPS, Git) ficaram fora da fala de propósito (regra 12); "agente" só aparece em técnicos.
- Nenhum número/data/preço do assunto usado; "quatro peças" é contagem da própria explicação.
